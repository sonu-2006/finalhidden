1. Executive Overview

Problem Formulation & Proposed Paradigm

✕ The Clinical Limitation of Post-Hoc Verification

Current hallucination safeguards (such as SelfCheckGPT or secondary LLM critics) operate post-hoc—evaluating statements only after the entire response has been generated. In clinical diagnostic scenarios, this introduces severe token latency, higher compute overhead, and risks delivering misleading diagnostic advice to clinicians.

✓ The Real-Time Probe Solution (RTHD)

We employ internal hidden-state probe classifiers to inspect the decoder's activation vector $h_t \in \mathbb{R}^{4096}$ at every decoding timestep $t$. By categorizing token states into Safe, At-Risk, and Hallucinating, the system flags the uncertainty phase transition before a factual diagnostic error is verbalized.

Key Research Questions Investigated

  • • Phase Transition Detection: Can intermediate representations detect an impending factual error before token generation enters the hallucinating regime?
  • • Cross-Architecture Generalization: Does probe discrimination hold across varying architectures (Qwen3-8B, Llama-3.1-8B, BioMistral-7B, Mistral-7B)?
  • • Pre-Emptive Intervention: Can early stopping at risk threshold $\theta$ suppress hallucinations while preserving response completeness?
Evaluation executed across four benchmark domains: EndoDiag, MedHallu, MedQA-USMLE, and PubMedQA.

2. Technical Methodology

System Architecture & Pipeline Pipeline

STAGE 01

Trajectory Collection

Medical QA prompt is fed to the backbone LLM (loaded in 4-bit NF4). At each generated token $t$, the hidden activation vector $h_t$ is extracted and cached.

h_t ∈ ℝ^4096 (Layers 4, 20, 32)
STAGE 02

State Annotation

Trajectory text is aligned with ground truth via ROUGE-L / keyword verifier. Tokens are mapped into Safe, AtRisk ($w=10$ window), or Hallucinating.

S = {Safe, AtRisk, Hallucinating}
STAGE 03

Probe Training

A calibrated 2-layer MLP classifier ($4096 \rightarrow 64 \rightarrow 3$) is trained with class-frequency weighting to estimate token-state posterior probabilities.

Risk r(t) = 1 - P(Safe | h_t)
STAGE 04

Pre-Emptive Intervention

Moving average risk $\bar{r}(t)$ is compared to threshold $\theta=0.85$. If $\bar{r}(t) > \theta$, critical point $t^*$ triggers immediate truncation.

Lead Time Δt = t_error - t*

Core Mathematical Definitions

1. Instantaneous Token Risk:
r(t) = 1.0 - P(y_t = \text{Safe} \mid h_t)
2. Critical Trigger Point:
t^* = \min \{ t \mid \text{MA}(r(t), w=5) \ge \theta \}
3. Early Detection Lead Time:
\Delta t = t_{\text{error}} - t^* \quad (\text{Valid when } t^* < t_{\text{error}})
4. Simulated Intervention Policy:
\text{Output} = \tau_{1:t^*} \quad (\text{Truncate upon confidence collapse})

git clone https://github.com/sonu-2006/finalhidden.git
cd finalhidden
pip install -r requirements.txt
2. Evaluate Saved Probe Checkpoints (Lead Time & Detection): 
python -m src.critical_detector \
    --labels results/endo_qwen_pilot20/states.jsonl \
    --model results/endo_qwen_pilot20/probe.pt \
    --theta 0.80 --k 5

    --labels results/endo_qwen_pilot20/states.jsonl \
    --model results/endo_qwen_pilot20/probe.pt \
    --stop_threshold 0.85 --min_tokens 10 --ma_window 5

6. Academic Transparency

Limitations & Clinical Governance Disclosures

1. Pilot Sample Boundary ($N=20$)

Each pilot experiment was evaluated across 20 trajectory samples due to compute and GPU memory constraints on Kaggle. These results serve as a rigorous proof-of-concept demonstrating internal representation shifts rather than an exhaustive epidemiological clinical trial.

2. Heuristic Ground Truth Annotations

Token-level ground truth states (Safe, At-Risk, Hallucinating) are generated via automated semantic overlap (ROUGE-L and keyword matching). They have not been independently validated by practicing medical clinicians.

3. Simulated Truncation Intervention

The reported hallucination reductions and output completeness metrics were obtained through simulated post-generation trajectory truncation at $t^*$, rather than active real-time steering or guided token decoding during the forward pass.

4. Medical Device Non-Readiness

This repository is strictly for academic and experimental evaluation. The findings do not establish clinical efficacy, regulatory safety, or readiness for direct patient care or unmonitored hospital deployment.
